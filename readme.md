# TP1 Regression on Women's Autonomy

## Project Overview

This repository contains the first practical assignment for the Masters-level statistics course, focused on women's autonomy. The project uses regression and machine learning methods to analyze factors that influence women's autonomy, compare models, and interpret results in a social science context.

## Objectives

- Explore and preprocess a dataset related to women's autonomy.
- Fit regression and machine learning models to predict autonomy outcomes.
- Evaluate models using appropriate metrics.
- Interpret coefficients, feature importance, and diagnostics.

## Contents

- Data preparation and feature engineering.
- Regression and machine learning model implementation.
- Model comparison and evaluation.
- Visualizations to support interpretation.
- Conclusions on women's autonomy predictors.

## Key Steps

1. Load and inspect the women's autonomy dataset.
2. Clean or transform variables relevant to autonomy measurement.
3. Fit regression and machine learning models.
4. Validate assumptions, analyze residuals, and assess model stability.
5. Compare model performance and identify key predictors.

## How to Use

- Open the project files in a code editor or notebook environment.
- Run the main analysis script or notebook step by step.
- Review the generated plots and summary statistics.

## Expected Deliverables

- A working autonomy analysis with supporting documentation.
- Clear interpretation of results and predictors.
- Discussion of model strengths and limitations.
